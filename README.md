# Personal Portfolio Website

This is a starter personal portfolio website.

## Files

- `index.html` - the page structure and content
- `css/style.css` - the design, layout, responsiveness, and dark mode styles
- `js/main.js` - the menu toggle, dark/light mode toggle, and footer year
- `assets/` - folder for images, icons, and resume file

## Next steps

1. Replace placeholder text with your real name and details.
2. Add your real projects.
3. Add your resume PDF to `assets/documents/resume.pdf`.
4. Add project screenshots to `assets/images/`.
5. Test the website in a browser.
